# Дозвон — звонить, пока не возьмут трубку

Android-приложение: вводите номер, нажимаете «Звонить до ответа», и телефон
сам перезванивает со своей SIM-карты, пока человек не ответит.

## Как пользоваться

1. Введите номер (или нажмите «Контакты»). Номер можно открыть и из другого
   приложения: ссылка `tel:` → «Открыть с помощью» → «Дозвон».
2. **Максимум попыток** — `0` значит звонить без ограничений.
3. **Пауза между звонками** — сколько секунд ждать перед следующей попыткой.
4. Нажмите «Звонить до ответа» и выдайте разрешения: звонки, состояние
   телефона, журнал вызовов, уведомления.
5. Остановить можно кнопкой «Остановить» в приложении или в уведомлении.

## Как приложение понимает, что ответили

После каждого звонка оно смотрит длительность вызова в журнале вызовов.
Android считает длительность исходящего звонка с момента ответа, поэтому:

- `0 с` — не ответили, сбросили, занято, недоступен → следующая попытка;
- больше `0 с` — ответили → дозвон останавливается, приходит уведомление.

Учтите:

- **Автоответчик или голосовая почта** оператора считается ответом.
- Если вы сами сбросите вызов до ответа, приложение позвонит снова после
  паузы. Чтобы прекратить, нажмите «Остановить».
- Пока идёт вызов, его не обрывают: гудки идут, пока звонок не сбросит
  оператор (обычно через 30–60 секунд) или собеседник.
- На некоторых прошивках (встречалось на отдельных Xiaomi и Huawei) длительность
  считается с момента набора. Тогда приложение остановится после первого
  звонка.
- На iPhone такое приложение сделать нельзя: iOS не даёт приложениям звонить
  самим.

## Сборка

APK собирает GitHub Actions (`.github/workflows/redial-apk.yml`) при каждом
пуше в `redial-app/`. Скачайте артефакт `redial-apk` на странице запуска во
вкладке **Actions**, распакуйте и установите `app-debug.apk` на телефон
(разрешите установку из неизвестных источников).

Локально (нужен Android SDK): `cd redial-app && ./gradlew assembleDebug`.

Каждая сборка в CI подписывается новым debug-ключом, поэтому перед установкой
новой версии старую, возможно, придётся удалить.
